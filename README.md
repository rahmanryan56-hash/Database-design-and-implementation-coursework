# Database Design and Implementation

## Overview

Coursework focused on designing and implementing a relational database for a fictional art gallery.

## Key Areas

* Designed a relational database using MySQL
* Created an Entity Relationship Diagram (ERD)
* Applied database design and normalisation principles
* Developed SQL queries to manage and retrieve data
* Implemented database tables, relationships and constraints

## Technologies

* MySQL
* SQL
* ERD / Database Design
